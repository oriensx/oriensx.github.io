# NationalDex：覆盖全部世代的开源宝可梦图鉴

网页版全国图鉴，作者 TimMikeladze，开源。收录 1025 种宝可梦，另外包含地区形态、超级进化与极巨化形态。切换世代之后，种族值、属性、特性、招式表与属性相克都按该世代的规则显示。

搜索覆盖宝可梦、招式、特性与道具。队伍编辑器会分析属性覆盖，也支持两只宝可梦的数据对照。收藏与自建名单保存在浏览器本地，安装为 PWA 之后可以离线使用。

# DogSpeak：来自网络视频的狗叫声分类数据集

面向动物交流与计算生物声学的音频数据集，素材取自数万条社交媒体视频，保留了真实环境中的噪声与差异。收录 77,202 段叫声序列，来自 156 只狗，覆盖吉娃娃、德国牧羊犬、哈士奇、比特与柴犬五个品种。

音频格式为 wav，按 dog_id 分目录存放，`metadata.csv` 记录文件名、品种、性别与个体编号。原 dog_7 目录的文件数超过单目录上限，拆分成 dog_7a 与 dog_7b。适用于品种分类、性别分类与生物声学模型预训练。许可为 CC BY-NC-SA 4.0，要求署名、非商业使用、相同方式共享。这个地址是官方数据集 ArlingtonCL2/DogSpeak_Dataset 的一份拷贝。

# 四个直接生成界面方案的工具

[Variant](https://variant.com/) 打开就是可以持续向下浏览的界面方案，适合在动手之前先确定方向。[Banani](https://www.banani.co/) 依据提示词生成多屏设计稿，支持局部修改，也可以导出到 Figma。[Google Stitch](https://stitch.withgoogle.com/) 基于 Gemini 生成界面与配套的设计系统。[Uizard](https://uizard.io/) 从文字描述生成可编辑的原型。

# 网页与微交互的灵感站点

整站参考方面，[Seesaw](https://www.seesaw.website/) 每天人工挑选网页案例，[Recent](https://recent.design/) 按 Web、界面、品牌、动效与插画等分类整理近期作品。[Godly](https://godly.website/) 收录量小，筛选标准更严。[Awwwards](https://www.awwwards.com/) 体量最大，偏向实验性动效，[SiteInspire](https://www.siteinspire.com/) 的筛选维度更细。落地页可以看 [Land-book](https://land-book.com/) 与 [Lapa Ninja](https://www.lapa.ninja/)。

细节参考方面，[Design Spells](https://designspells.com/) 收集微交互、彩蛋与容易被忽略的界面处理。[60fps](https://60fps.design/) 与 [Spotted in Prod](https://spottedinprod.com/) 收录的都是已上线产品中的交互。[Refero](https://refero.design/) 与 [Mobbin](https://mobbin.com/) 支持按页面类型检索真实产品的界面截图。

# 一批可以直接复制进项目的动效组件库

[React Bits](https://reactbits.dev/) 收录文字、背景与交互动画，既可以复制组件源码，也可以通过 CLI 安装，JS 与 TS、CSS 与 Tailwind 各有一份实现。[Magic UI](https://magicui.design/) 与 [Aceternity UI](https://ui.aceternity.com/) 都基于 React、Tailwind 与 Motion，前者更贴近 shadcn/ui，后者侧重落地页区块与模板。[Motion Primitives](https://motion-primitives.com/) 规模更小，开源，可以自行修改。

同类项目还有 [Bundui](https://bundui.io/) 与 [ReUI](https://reui.io/)，技术组合相同。[Cult UI](https://www.cult-ui.com/) 偏向 AI 产品界面。[Animata](https://animata.design/) 与 [Eldora UI](https://eldoraui.site/) 是开源动画组件集合。[Motiq](https://motiq.dev/) 提供 shadcn registry，安装后得到可修改的源码。[21st.dev](https://21st.dev/) 是社区组件市场，其中也能检索到带动画的区块。
